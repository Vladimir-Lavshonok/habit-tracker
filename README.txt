ТРЕКЕР ПРИВЫЧЕК — автономная веб-версия (PWA)
Автор: Vladimir Lavshonok

Эта версия не связана с Claude: пользователям не нужны ни аккаунт, ни регистрация.
Данные хранятся только на устройстве пользователя (в памяти браузера) и никуда не отправляются.
После первого открытия приложение работает без интернета.


1. РАЗМЕСТИТЬ ПРИЛОЖЕНИЕ В ИНТЕРНЕТЕ (один раз, делает автор)
------------------------------------------------------------
Нужен любой хостинг статических сайтов с HTTPS. Загрузите на него СОДЕРЖИМОЕ этой папки
(index.html, *.js, sw.js, manifest.webmanifest и папку icons) — файл README.txt загружать не обязательно.

Вариант А — GitHub Pages (бесплатно, постоянная ссылка):
  1) Зарегистрируйтесь на github.com.
  2) Нажмите «+» → «New repository», имя, например, habit-tracker, тип Public → «Create repository».
  3) На странице репозитория: «uploading an existing file» (или «Add file» → «Upload files»).
  4) Перетащите в окно все файлы и папку icons → «Commit changes».
  5) «Settings» → «Pages» → Source: «Deploy from a branch», Branch: main, папка / (root) → «Save».
  6) Через 1–2 минуты сайт будет доступен по адресу https://ВАШ-ЛОГИН.github.io/habit-tracker/

Вариант Б — Netlify Drop (быстрее всего):
  1) Откройте https://app.netlify.com/drop и перетащите эту папку в окно.
  2) Зарегистрируйтесь бесплатно, чтобы ссылка стала постоянной.
  3) В «Site configuration» можно поменять адрес на понятный, например habit-tracker-lavshonok.netlify.app

Вариант В — Cloudflare Pages: «Workers & Pages» → «Create» → «Pages» → «Upload assets» → перетащите папку.

Открыть index.html прямо с диска (двойным щелчком) можно для просмотра, но установка на телефон
и работа без интернета включаются только на сайте с https://.


2. УСТАНОВИТЬ НА iPHONE / iPAD
------------------------------
  1) Откройте ссылку на приложение в Safari.
  2) Нажмите «Поделиться» (квадрат со стрелкой вверх).
  3) Выберите «На экран «Домой»» → «Добавить».
  4) Запускайте со значка: приложение открывается на весь экран и работает без интернета.
  Системные уведомления на iPhone доступны только у установленного приложения (iOS 16.4+):
  раздел «Напоминания» → «Системные уведомления».

3. УСТАНОВИТЬ НА ANDROID
------------------------
  1) Откройте ссылку в Chrome.
  2) Нажмите «Установить» в подсказке или «⋮» → «Установить приложение» / «Добавить на главный экран».

4. УСТАНОВИТЬ НА КОМПЬЮТЕР
--------------------------
  Chrome / Edge: значок установки в правой части адресной строки (или меню → «Установить Трекер привычек»).
  Safari на Mac (17+): «Файл» → «Добавить в Dock».


5. ВАЖНО ЗНАТЬ
--------------
  • Каждый пользователь видит только свои данные — они лежат на его устройстве.
  • Данные НЕ синхронизируются между устройствами. Перенос: «Данные» → «Скачать JSON»
    на старом устройстве → «Выбрать файл…» на новом.
  • Если очистить данные сайта в браузере или удалить приложение, записи пропадут —
    регулярно делайте резервную копию (JSON).
  • Напоминания приходят, пока приложение открыто или свёрнуто. Уведомления при полностью
    закрытом приложении требуют собственного сервера push-уведомлений.


6. КАК ВЫПУСТИТЬ ОБНОВЛЕНИЕ
---------------------------
  1) Замените файлы на хостинге новыми.
  2) В файле sw.js увеличьте номер в строке  const VERSION = 'habit-tracker-v4';  (например, на v5),
     а в index.html — ?v=4 у скриптов. Иначе у пользователей может остаться старая версия из кэша.
  Пользователи получат обновление при следующем открытии приложения (иногда — со второго запуска).
